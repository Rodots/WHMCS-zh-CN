## 项目介绍

- **人工排查，与官方同步**：本项目汉化文件均经人工逐一排查，确保与官方语言文件完全同步（零遗漏，但不排除可能存在少量错误）。
- **翻译方式说明**：由于汉化工程量庞大，译文统一先由 AI 机器翻译，再经人工二次校对与优化。理论上，高版本翻译文件可向下兼容低版本。
- **特殊情况处理**：部分语句因变量过多而难以理解，此类情况下保留原文，不作翻译。
- **历史版本**：当前 `main` 分支仅提供 WHMCS 9.x 汉化包；如需 v7.x、v8.x 版本的翻译包，请前往 [`7.x-8.x`](https://github.com/Rodots/WHMCS-zh-CN/tree/7.x-8.x) 分支获取。

## 使用方法

请根据您的 WHMCS 版本选择对应的汉化文件并下载。

1. **上传覆盖**
   将下载的语言文件上传至 WHMCS 根目录，覆盖原有文件。

2. **管理员语言设置**
   - 注销当前管理员账户，在登录页面选择“中文”。
   - 登录后，点击“我的帐户(My Account)”，将“语言(Language)”更改为“中文(chinese)”。
   - 在“确认密码(Confirm Password)”行输入管理员密码，最后点击“保存更改(Save Changes)”按钮。

3. **系统默认语言设置**
   - 转到“系统设置 > 常规设置(Setup > General Settings)”。
   - 点击“本地化(Localisation)”选项卡，将“默认语言(Default Language)”设置为“中文(chinese)”。
   - 最后点击“保存更改(Save Changes)”按钮。
